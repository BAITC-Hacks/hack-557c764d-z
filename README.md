# Два задания хакатона

Нужен **Python 3.10+**. Внешние библиотеки, API-ключи и интернет не требуются.
Откройте терминал в папке проекта и запустите:

```sh
python -X utf8 classify_messages.py
python -X utf8 filter_alerts.py
```

Флаг `-X utf8` обеспечивает корректный вывод кириллицы, в том числе в Windows.

## 1. Классификатор обращений

`messages.txt` содержит все 5 обращений из задания, по одному на строку.
Скрипт печатает для каждого текста категорию и один черновик ответа на русском.
Использованы правила по ключевым словам — такой подход разрешён заданием.
Результат: **справка, жалоба, другое, жалоба, другое**.
Категория «справка» означает запрос документа; вопрос о парковке относится к «другое».
Ответы — шаблоны: скрипт не отправляет сообщения и не записывает на консультацию.
Правила рассчитаны на небольшой набор примеров и могут ошибаться на новых формулировках.

## 2. Фильтр алертов

`events.json` содержит все 8 перечисленных событий. Для каждого указаны текст
`message` и уровень `level`. Скрипт оставляет события с `level == "critical"`:

```text
disk 90% (critical)
payment failed (critical)
db timeout (critical)
критичных 3
```

Отфильтровано 5 некритичных событий. Использован обычный фильтр без агентов и LLM.
На скриншоте нет исходного JSON из README организаторов, поэтому структура файла
восстановлена по приведённому списку событий; их тексты, уровни и порядок сохранены.

Для своих данных можно передать путь: `python classify_messages.py other_messages.txt`
или `python filter_alerts.py other_events.json`. Файлы должны быть в UTF-8.
